## 一、开发启动策略

### 1.1 为什么从 nexusix-common 开始?

**nexusix-common** 是整个项目的**基础设施层**,所有其他模块都直接或间接依赖它。必须优先实现以下核心组件:

```
依赖关系:
nexusix-boot (启动模块)
  ↓
业务模块 (tenant/iam/org/billing...)
  ↓
nexusix-core (核心框架 - 依赖 common)
  ↓
nexusix-common (公共基础 - 无依赖) ← 从这里开始!
```

**必要性**:
1. **统一响应结构** (`ApiResponse`): 所有 Controller 返回统一格式
2. **全局异常处理** (`GlobalExceptionHandler`): 捕获并标准化异常
3. **工具类库** (`IdUtils`, `DateUtils`): 提供通用能力
4. **枚举和常量** (`StatusEnum`, `GlobalConstant`): 避免魔法值

#### ✅ 任务 1.1: 实现统一响应结构 (Sa-Token 封装)

**文件**: `nexusix-common/src/main/java/com/shy/nexusix/common/result/ApiResponse.java`

```java
package com.shy.nexusix.common.result;

import cn.dev33.satoken.stp.StpUtil;
import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;

import java.io.Serializable;

/**
 * 统一 API 响应封装 (Sa-Token 增强版)
 *
 * @param <T> 响应数据类型
 */
@Data
@NoArgsConstructor
@AllArgsConstructor
public class ApiResponse<T> implements Serializable {

    private static final long serialVersionUID = 1L;

    /**
     * 响应码 (200-成功, 其他-失败)
     */
    private Integer code;

    /**
     * 响应消息
     */
    private String message;

    /**
     * 响应数据
     */
    private T data;

    /**
     * 请求追踪 ID (从 Sa-Token 获取)
     */
    private String traceId;

    /**
     * 服务器时间戳
     */
    private Long timestamp;

    public ApiResponse(Integer code, String message, T data) {
        this.code = code;
        this.message = message;
        this.data = data;
        this.traceId = StpUtil.getExtra("traceId") != null 
            ? StpUtil.getExtra("traceId").toString() 
            : null;
        this.timestamp = System.currentTimeMillis();
    }

    /**
     * 成功响应 (无数据)
     */
    public static <T> ApiResponse<T> success() {
        return new ApiResponse<>(ResultCode.SUCCESS.getCode(), ResultCode.SUCCESS.getMessage(), null);
    }

    /**
     * 成功响应 (带数据)
     */
    public static <T> ApiResponse<T> success(T data) {
        return new ApiResponse<>(ResultCode.SUCCESS.getCode(), ResultCode.SUCCESS.getMessage(), data);
    }

    /**
     * 成功响应 (自定义消息)
     */
    public static <T> ApiResponse<T> success(String message, T data) {
        return new ApiResponse<>(ResultCode.SUCCESS.getCode(), message, data);
    }

    /**
     * 失败响应
     */
    public static <T> ApiResponse<T> error(Integer code, String message) {
        return new ApiResponse<>(code, message, null);
    }

    /**
     * 失败响应 (使用枚举)
     */
    public static <T> ApiResponse<T> error(ResultCode resultCode) {
        return new ApiResponse<>(resultCode.getCode(), resultCode.getMessage(), null);
    }

    /**
     * 失败响应 (自定义消息)
     */
    public static <T> ApiResponse<T> error(ResultCode resultCode, String message) {
        return new ApiResponse<>(resultCode.getCode(), message, null);
    }

    /**
     * 未授权响应 (Sa-Token)
     */
    public static <T> ApiResponse<T> unauthorized() {
        return new ApiResponse<>(ResultCode.UNAUTHORIZED.getCode(), ResultCode.UNAUTHORIZED.getMessage(), null);
    }

    /**
     * 权限不足响应 (Sa-Token)
     */
    public static <T> ApiResponse<T> forbidden() {
        return new ApiResponse<>(ResultCode.FORBIDDEN.getCode(), ResultCode.FORBIDDEN.getMessage(), null);
    }
}
```

package com.shy.nexusix.common.result;

import cn.dev33.satoken.exception.NotLoginException;
import cn.dev33.satoken.exception.NotPermissionException;
import lombok.AllArgsConstructor;
import lombok.Getter;

/**
 * 响应码枚举 (Sa-Token 集成版)
 */
@Getter
@AllArgsConstructor
public enum ResultCode {

    // ========== 通用响应码 ==========
    SUCCESS(200, "操作成功"),
    FAIL(500, "操作失败"),
    UNAUTHORIZED(401, "未授权,请先登录"),
    FORBIDDEN(403, "权限不足,禁止访问"),
    NOT_FOUND(404, "资源不存在"),
    PARAM_ERROR(400, "参数校验失败"),

    // ========== Sa-Token 相关 (0xxx) ==========
    TOKEN_INVALID(10001, "Token 无效或已过期"),
    TOKEN_EXPIRED(10002, "Token 已过期,请重新登录"),
    BE_REPLACED(10003, "账号已在其他设备登录,您已被强制下线"),
    KICK_OUT(10004, "账号已被管理员强制下线"),
    NO_LOGIN(10005, "尚未登录,请先登录"),
    NOT_PERMISSION(10006, "权限不足,无法访问该资源"),

    // ========== 租户相关 (1xxx) ==========
    TENANT_CODE_EXISTS(1001, "租户编码已存在"),
    PARENT_TENANT_NOT_FOUND(1002, "父租户不存在"),
    TENANT_NOT_FOUND(1003, "租户不存在"),
    TENANT_FROZEN(1004, "租户已冻结"),
    TENANT_EXPIRED(1005, "租户已过期"),

    // ========== 用户相关 (2xxx) ==========
    USER_NOT_FOUND(2001, "用户不存在"),
    USERNAME_EXISTS(2002, "用户名已存在"),
    PASSWORD_ERROR(2003, "密码错误"),
    USER_DISABLED(2004, "用户已被禁用"),
    LOGIN_FAIL_LIMIT(2005, "登录失败次数过多,账号已锁定"),

    // ========== 权限相关 (3xxx) ==========
    PERMISSION_DENIED(3001, "权限不足"),
    ROLE_NOT_FOUND(3002, "角色不存在"),

    // ========== 组织架构相关 (4xxx) ==========
    DEPT_NOT_FOUND(4001, "部门不存在"),
    DEPT_HAS_CHILDREN(4002, "部门下存在子部门或用户,无法删除"),
    POST_NOT_FOUND(4003, "岗位不存在"),

    // ========== 计费相关 (5xxx) ==========
    PACKAGE_NOT_FOUND(5001, "套餐不存在"),
    QUOTA_INSUFFICIENT(5002, "配额不足"),
    ORDER_NOT_FOUND(5003, "订单不存在"),

    // ========== 参数校验 (6xxx) ==========
    VALIDATION_ERROR(6001, "参数校验失败"),
    ;

    private final Integer code;
    private final String message;

    /**
     * 从 Sa-Token 异常转换为 ResultCode
     */
    public static ResultCode fromSaTokenException(Exception e) {
        if (e instanceof NotLoginException) {
            NotLoginException exception = (NotLoginException) e;
            switch (exception.getType()) {
                case NotLoginException.NOT_TOKEN:
                    return NO_LOGIN;
                case NotLoginException.INVALID_TOKEN:
                    return TOKEN_INVALID;
                case NotLoginException.TOKEN_TIMEOUT:
                    return TOKEN_EXPIRED;
                case NotLoginException.BE_REPLACED:
                    return BE_REPLACED;
                case NotLoginException.KICK_OUT:
                    return KICK_OUT;
                default:
                    return NO_LOGIN;
            }
        } else if (e instanceof NotPermissionException) {
            return NOT_PERMISSION;
        }
        return FAIL;
    }
}

#### ✅ 任务 1.3: 实现全局异常处理器 (Sa-Token 深度集成)

**文件**: `nexusix-common/src/main/java/com/shy/nexusix/common/exception/GlobalExceptionHandler.java`

```java
package com.shy.nexusix.common.exception;

import cn.dev33.satoken.exception.NotLoginException;
import cn.dev33.satoken.exception.NotPermissionException;
import cn.dev33.satoken.exception.NotRoleException;
import com.shy.nexusix.common.result.ApiResponse;
import com.shy.nexusix.common.result.ResultCode;
import lombok.extern.slf4j.Slf4j;
import org.springframework.validation.BindException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

/**
 * 全局异常处理器 (Sa-Token 深度集成版)
 */
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    /**
     * 业务异常
     */
    @ExceptionHandler(BusinessException.class)
    public ApiResponse<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: code={}, message={}", e.getCode(), e.getMessage());
        return ApiResponse.error(e.getCode(), e.getMessage());
    }

    /**
     * Sa-Token 未登录异常 (详细分类)
     */
    @ExceptionHandler(NotLoginException.class)
    public ApiResponse<Void> handleNotLoginException(NotLoginException e) {
        ResultCode resultCode = ResultCode.fromSaTokenException(e);
        
        // 根据异常类型记录不同级别的日志
        switch (e.getType()) {
            case NotLoginException.NOT_TOKEN:
                log.warn("未提供 Token: {}", e.getMessage());
                break;
            case NotLoginException.INVALID_TOKEN:
                log.warn("Token 无效: {}", e.getMessage());
                break;
            case NotLoginException.TOKEN_TIMEOUT:
                log.info("Token 已过期: {}", e.getMessage());
                break;
            case NotLoginException.BE_REPLACED:
                log.warn("账号被顶替: {}", e.getMessage());
                break;
            case NotLoginException.KICK_OUT:
                log.warn("账号被踢出: {}", e.getMessage());
                break;
            default:
                log.warn("未登录: {}", e.getMessage());
        }
        
        return ApiResponse.error(resultCode);
    }

    /**
     * Sa-Token 权限不足异常
     */
    @ExceptionHandler(NotPermissionException.class)
    public ApiResponse<Void> handleNotPermissionException(NotPermissionException e) {
        log.warn("权限不足: 缺少权限 {}, 当前登录用户: {}", 
            e.getPermission(), 
            getCurrentUserId());
        return ApiResponse.forbidden();
    }

    /**
     * Sa-Token 角色不足异常
     */
    @ExceptionHandler(NotRoleException.class)
    public ApiResponse<Void> handleNotRoleException(NotRoleException e) {
        log.warn("角色不足: 缺少角色 {}, 当前登录用户: {}", 
            e.getRole(), 
            getCurrentUserId());
        return ApiResponse.forbidden();
    }

    /**
     * 参数校验异常 (@Valid)
     */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<Void> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldError().getDefaultMessage();
        log.warn("参数校验失败: field={}, message={}", 
            e.getBindingResult().getFieldError().getField(), 
            message);
        return ApiResponse.error(ResultCode.PARAM_ERROR.getCode(), message);
    }

    /**
     * 参数绑定异常
     */
    @ExceptionHandler(BindException.class)
    public ApiResponse<Void> handleBindException(BindException e) {
        String message = e.getBindingResult().getFieldError().getDefaultMessage();
        log.warn("参数绑定失败: field={}, message={}", 
            e.getBindingResult().getFieldError().getField(), 
            message);
        return ApiResponse.error(ResultCode.PARAM_ERROR.getCode(), message);
    }

    /**
     * 系统异常 (兜底)
     */
    @ExceptionHandler(Exception.class)
    public ApiResponse<Void> handleException(Exception e) {
        log.error("系统异常: {}", e.getMessage(), e);
        return ApiResponse.error(ResultCode.FAIL);
    }

    /**
     * 获取当前登录用户 ID (Sa-Token)
     */
    private Object getCurrentUserId() {
        try {
            return cn.dev33.satoken.stp.StpUtil.getLoginId();
        } catch (Exception e) {
            return "未登录";
        }
    }
}
```

#### ✅ 任务 1.4: 实现业务异常类 (Sa-Token 兼容)

**文件**: `nexusix-common/src/main/java/com/shy/nexusix/common/exception/BusinessException.java`

```java
package com.shy.nexusix.common.exception;

import cn.dev33.satoken.exception.SaTokenException;
import com.shy.nexusix.common.result.ResultCode;
import lombok.Getter;

/**
 * 业务异常 (Sa-Token 兼容版)
 */
@Getter
public class BusinessException extends RuntimeException {

    private final Integer code;

    public BusinessException(String message) {
        super(message);
        this.code = ResultCode.FAIL.getCode();
    }

    public BusinessException(Integer code, String message) {
        super(message);
        this.code = code;
    }

    public BusinessException(ResultCode resultCode) {
        super(resultCode.getMessage());
        this.code = resultCode.getCode();
    }

    public BusinessException(ResultCode resultCode, String message) {
        super(message);
        this.code = resultCode.getCode();
    }

    /**
     * 从 Sa-Token 异常创建业务异常
     */
    public static BusinessException fromSaTokenException(SaTokenException e) {
        ResultCode resultCode = ResultCode.fromSaTokenException(e);
        return new BusinessException(resultCode, e.getMessage());
    }

    /**
     * 检查是否为 Sa-Token 相关异常
     */
    public boolean isSaTokenRelated() {
        return this.code >= 10000 && this.code < 11000;
    }
}
```

import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.baomidou.mybatisplus.extension.service.impl.ServiceImpl;
import com.shy.nexusix.common.exception.BusinessException;
import com.shy.nexusix.common.result.ResultCode;
import com.shy.nexusix.tenant.converter.TenantConverter;
import com.shy.nexusix.tenant.dto.CreateTenantDTO;
import com.shy.nexusix.tenant.entity.SysTenant;
import com.shy.nexusix.tenant.mapper.SysTenantMapper;
import com.shy.nexusix.tenant.service.ISysTenantService;
import com.shy.nexusix.tenant.vo.TenantVO;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.stream.Collectors;

/**
 * 租户服务实现
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class SysTenantServiceImpl extends ServiceImpl<SysTenantMapper, SysTenant> implements ISysTenantService {

    private final TenantConverter tenantConverter;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Long createTenant(CreateTenantDTO dto) {
        // 1. 校验租户编码唯一性
        LambdaQueryWrapper<SysTenant> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(SysTenant::getTenantCode, dto.getTenantCode());
        if (this.count(wrapper) > 0) {
            throw new BusinessException(ResultCode.TENANT_CODE_EXISTS);
        }

        // 2. 校验父租户存在
        if (dto.getParentId() != null && dto.getParentId() > 0) {
            SysTenant parent = this.getById(dto.getParentId());
            if (parent == null) {
                throw new BusinessException(ResultCode.PARENT_TENANT_NOT_FOUND);
            }
        }

        // 3. 构建 Entity
        SysTenant tenant = tenantConverter.toEntity(dto);
        tenant.setParentId(dto.getParentId() != null ? dto.getParentId() : 0L);
        tenant.setStatus(1);
        tenant.setCreateBy(StpUtil.getLoginIdAsLong());
        tenant.setUpdateBy(StpUtil.getLoginIdAsLong());

        // 4. 计算 ancestors (物化路径)
        if (tenant.getParentId() > 0) {
            SysTenant parent = this.getById(tenant.getParentId());
            tenant.setAncestors(parent.getAncestors() + "," + parent.getId());
        } else {
            tenant.setAncestors("0");
        }

        // 5. 插入数据库
        this.save(tenant);

        log.info("创建租户成功: tenantId={}, tenantCode={}", tenant.getId(), tenant.getTenantCode());
        return tenant.getId();
    }

    @Override
    public List<TenantVO> getTenantTree(Long parentId) {
        LambdaQueryWrapper<SysTenant> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(SysTenant::getParentId, parentId != null ? parentId : 0L)
               .orderByAsc(SysTenant::getCreateTime);

        List<SysTenant> tenants = this.list(wrapper);
        return tenants.stream()
                      .map(tenantConverter::toVO)
                      .collect(Collectors.toList());
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void updateTenantStatus(Long tenantId, Integer status) {
        SysTenant tenant = this.getById(tenantId);
        if (tenant == null) {
            throw new BusinessException(ResultCode.TENANT_NOT_FOUND);
        }

        tenant.setStatus(status);
        tenant.setUpdateBy(StpUtil.getLoginIdAsLong());
        this.updateById(tenant);

        log.info("更新租户状态: tenantId={}, status={}", tenantId, status);
    }
}

                if (tenantId == null) {

                return new LongValue(tenantId);

            public String getTenantIdColumn() {
                return "tenant_id";
            }

            @Override
            public boolean ignoreTable(String tableName) {
                // 系统级表不参与多租户过滤
                return ignoreTables != null && ignoreTables.contains(tableName);
            }
        }));

        // 2. 分页插件 (PostgreSQL)
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.POSTGRE_SQL));

#### 3.2.3 权限校验 AOP 切面

package com.shy.nexusix.core.permission;

import cn.dev33.satoken.stp.StpUtil;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.reflect.MethodSignature;
import org.springframework.stereotype.Component;

import java.lang.reflect.Method;

/**
 * 权限校验切面
 */
@Aspect
@Component
public class PermissionAspect {

    @Around("@annotation(com.shy.nexusix.core.permission.RequirePermission)")
    public Object checkPermission(ProceedingJoinPoint joinPoint) throws Throwable {
        // 获取方法上的注解
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        Method method = signature.getMethod();
        RequirePermission annotation = method.getAnnotation(RequirePermission.class);

        if (annotation != null) {
            String permCode = annotation.value();
            // 调用 Sa-Token 进行权限校验
            StpUtil.checkPermission(permCode);
        }

        return joinPoint.proceed();
    }
}

## 四、关键集成点说明

### 4.1 模块间交互原则

**核心原则**: 业务模块之间**不直接依赖**,通过以下方式交互:

1. **共享 Entity**: 通过 nexusix-core 或 nexusix-common 共享实体类
2. **Service 注入**: 在同一个 Spring 容器中,可以直接注入其他模块的 Service
3. **事件驱动**: 使用 Spring Event 解耦模块间通信

**示例**: 订单模块需要查询租户信息

```java
@Service
@RequiredArgsConstructor
public class BillOrderServiceImpl extends ServiceImpl<BillOrderMapper, BillOrder> implements IBillOrderService {

    private final ISysTenantService tenantService; // 直接注入租户模块的 Service

    @Override
    public Long createOrder(CreateOrderDTO dto) {
        // 校验租户是否存在
        SysTenant tenant = tenantService.getById(dto.getTenantId());
        if (tenant == null) {
            throw new BusinessException(ResultCode.TENANT_NOT_FOUND);
        }
        // ... 创建订单逻辑
    }
}
```

---

### 4.2 全局异常处理配置

已在 **任务 1.3** 中实现 `GlobalExceptionHandler`,关键点:

1. **@RestControllerAdvice**: 全局异常拦截
2. **优先级**: 具体异常 → 通用异常 (BusinessException → Exception)
3. **日志记录**: warn 级别记录业务异常,error 级别记录系统异常
4. **统一响应**: 所有异常返回 `ApiResponse` 格式
5. **Sa-Token 深度集成**: 区分不同类型的未登录异常 (Token 无效/过期/被顶替/被踢出)

---

### 4.3 统一响应配置

已在 **任务 1.1** 中实现 `ApiResponse`,关键点:

1. **泛型支持**: `ApiResponse<T>` 支持任意数据类型
2. **静态工厂方法**: `success()`, `success(data)`, `error(code, message)`
3. **序列化**: 实现 `Serializable` 接口,支持 Redis 缓存
4. **Sa-Token 增强**: 自动添加 traceId 和 timestamp
5. **专用方法**: `unauthorized()`, `forbidden()` 快速返回认证/授权错误

## 六、常见问题与解决方案

### Q1: 多租户拦截器未生效?

**原因**: 
1. `TenantContext.setTenantId()` 未调用
2. 表名在 `ignore-tables` 配置中

**解决**:
```java
// 在登录拦截器或过滤器中设置
@Component
public class TenantInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        Long tenantId = extractTenantIdFromToken(request); // 从 Token 中提取
        TenantContext.setTenantId(tenantId);
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex) {
        TenantContext.clear(); // 清理
    }
}
```

---

### Q2: 逻辑删除未生效?

**原因**: 
1. 实体类缺少 `@TableLogic` 注解
2. application.yml 未配置 `logic-delete-field`

**解决**:
```java
// 方案 1: 添加注解 (推荐)
@TableLogic
@TableField("is_deleted")
private Integer isDeleted;

// 方案 2: 全局配置 (application.yml)
mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: isDeleted
      logic-delete-value: 1
      logic-not-delete-value: 0
```

---

### Q3: MapStruct Converter 未生成实现类?

**原因**: Maven 编译时未触发注解处理器

**解决**:
```bash
mvn clean compile
```

检查 `target/generated-sources/annotations` 目录下是否生成了 `*ConverterImpl.java`

---

### Q4: Sa-Token 权限校验失败?

**原因**: 
1. `StpInterface` 未实现或未注册为 Spring Bean
2. 数据库中未配置用户权限数据

**解决**:
```java
@Component // 确保标注 @Component
public class StpInterfaceImpl implements StpInterface {
    // ...
}
```

---

### Q5: Sa-Token 返回的异常信息不够友好?

**解决**: 在 `GlobalExceptionHandler` 中已经对 Sa-Token 异常进行了详细分类和处理,会返回统一的 `ApiResponse` 格式,包含清晰的中文提示。
