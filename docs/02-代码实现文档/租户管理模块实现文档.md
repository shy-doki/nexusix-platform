## 1. 模块概述

### 1.1 模块定位

`nexusix-tenant` 是 NexusIX-Platform 多租户 SaaS 平台的**租户与租户策略管理中心**，承担以下核心职责：

- **租户管理**：租户的 CRUD、批量操作、状态切换、树形结构查询
- **租户策略管理**：部门/角色与租户的绑定关系管理（即 `sys_tenant_policy` 表）
- **租户层级管理**：基于物化路径的无限层级租户树，支持分配子租户、分配父租户
- **租户自助注册与审核**：企业用户自助注册（PENDING 状态），平台管理员审核
- **租户切换**：登录用户在多个所属租户间切换工作上下文
- **字段级权限控制**：基于 `UserContextDTO.FieldPermission` 动态控制可见字段

### 1.2 核心特性

1. **物化路径树形结构**：`sys_tenant` 表通过 `parent_id/path/level` 字段实现物化路径树形结构，path 格式如 `TENANT_001/TENANT_002/TENANT_003`，支持高效的子树查询与级联操作。
2. **租户状态机**：`PENDING → ENABLED / DISABLED → EXPIRED` 之间的合法转换由 `GlobalEnum.TenantStatus.isValidTransition` 控制。
3. **级联停用**：停用父租户时，利用 path 前缀匹配（`likeRight`）自动级联停用所有子租户，禁用原因标记为 `PARENT_CASCADE:{parentId}`。
4. **环状结构检测**：分配父租户时，通过 path 包含检测避免形成环状结构。
5. **超级管理员/非超级管理员审计字段控制**：与 IAM 模块一致，超级管理员可填写审计字段，非超级管理员由系统强制覆盖。
6. **字段级权限**：查询时通过 `LambdaQueryWrapper.select()` 动态选择可见列；写入时清除不可操作字段值。

### 1.3 技术栈

| 类别 | 选型 |
|------|------|
| ORM | MyBatis-Plus 3.5.12 |
| 上下文 | `UserContext.getUserContext()` 读取 Sa-Token Session |
| 对象转换 | MapStruct |
| 数据库 | PostgreSQL |

#### 3.1.1 物化路径示例

```
根租户（id=101, tenantCode=TENANT_001, path=TENANT_001, level=1）
├── 子租户（id=111, tenantCode=TENANT_002, path=TENANT_001/TENANT_002, level=2）
│   └── 孙租户（id=121, tenantCode=TENANT_003, path=TENANT_001/TENANT_002/TENANT_003, level=3）
└── 子租户（id=112, tenantCode=TENANT_004, path=TENANT_001/TENANT_004, level=2）
```

**子树查询**：`WHERE path LIKE 'TENANT_001/%'` 获取 id=101 的所有后代节点。

#### 3.1.2 禁用原因编码

| 编码 | 说明 |
|------|------|
| `ADMIN_DISABLE` | 管理员主动停用 |
| `PARENT_CASCADE:{parentId}` | 父租户级联停用 |
| `REVIEW_REJECTED:{reason}` | 审核拒绝 |
| `null`（启用时清除） | 启用状态无禁用原因 |

#### 4.1.1 新增租户（示例）

- **URL**：`POST /NexusIxService/tenant/add`
- **请求体**（`SysTenantAddRTO`）：

```json
{
  "tenantCode": "TEN0000001",
  "tenantName": "某某科技有限公司",
  "tenantType": "互联网",
  "tenantDesc": "这是一家互联网公司",
  "parentCode": "1987654321098765432",
  "parentName": "阿里云",
  "contactName": "张三",
  "contactPhone": "13812348000",
  "status": "正常",
  "expireTime": "2026-12-31 23:59:59",
  "packageCode": "1001",
  "packageName": "企业版套餐",
  "extAttributes": "{\"industry\": \"tech\", \"quota\": 100}"
}
```

**校验规则**：

- `tenantCode / tenantName / tenantType / contactName / contactPhone / status / expireTime / packageCode / packageName`：`@NotBlank` / `@NotNull`

- `contactPhone`：正则 `^1[3-9]\d{9}$`（中国大陆手机号）
- `expireTime`：`@Future` 不能早于当前时间
- `status`：`@EnumField` 校验必须为 `GlobalEnum.TenantStatus` 枚举值

- **响应示例**：

```json
{
  "code": 200,
  "msg": "success",
  "data": 1
}
```

## 5. 核心业务逻辑实现

### 5.1 物化路径树形结构构建

**位置**：`SysTenantServiceImpl.queryTenantTreeList`

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 获取查询操作的字段权限                                        │
│     getTableFieldPermission("query")                            │
│     若为空或无权限 → 抛出 "无权查询租户信息"                       │
└────────────────────────┬────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. 合并可见字段与业务必选字段                                    │
│     queryFields = visibleFields + TREE_MANDATORY_FIELDS         │
│     TREE_MANDATORY_FIELDS = [id, tenant_code, tenant_name,      │
│                               parent_id, path]                  │
```

```java
@Transactional(rollbackFor = Exception.class)
public Integer addTenant(SysTenantAddRTO addParam) {
    // 1. 获取创建操作的字段权限
    List<String> visibleFields = getTableFieldPermission("create");
    if (visibleFields == null || visibleFields.isEmpty()) {
        throw new BusinessException("无权新增租户");
    }

    // 2. 校验租户编码唯一性
    if (this.count(new LambdaQueryWrapper<SysTenant>()
            .eq(SysTenant::getTenantCode, addParam.getTenantCode())
            .eq(SysTenant::getIsDeleted, "NOT_DELETED")) > 0) {
        throw new BusinessException("租户编码已存在");
    }

    // 3. 查询父租户信息
    SysTenant parentTenant = null;
    if (addParam.getParentCode() != null && !"0".equals(addParam.getParentCode())) {
        parentTenant = this.getOne(new LambdaQueryWrapper<SysTenant>()
                .eq(SysTenant::getId, addParam.getParentCode())
                .eq(SysTenant::getIsDeleted, "NOT_DELETED"));
        if (parentTenant == null) throw new BusinessException("父租户不存在");

        // 校验父租户状态
        if ("DISABLED".equals(parentTenant.getStatus())) {
            throw new BusinessException("父租户已停用，无法新增子租户");
        }
        if ("EXPIRED".equals(parentTenant.getStatus())) {
            throw new BusinessException("父租户已过期，无法新增子租户");
        }
    }

    // 4. MapStruct 转换 RTO → Entity
    SysTenant entity = sysTenantConverter.toEntityFromAdd(addParam);

    // 5. 计算物化路径
    if (entity.getPath() == null || entity.getPath().isEmpty()) {
        if (parentTenant != null) {
            // 子租户路径 = 父租户路径 + / + 当前租户编码
            entity.setPath(parentTenant.getPath() + "/" + addParam.getTenantCode());
        } else {
            // 根租户路径 = 自身租户编码
            entity.setPath(addParam.getTenantCode());
        }
    }

    // 6. 设置默认值
    entity.setHasChildren(false);

    // 7. 超级管理员/非超级管理员审计字段控制
    boolean isSuperAdmin = StpUtil.hasRole("super_admin");
    if (isSuperAdmin) {
        // 超级管理员：未填写则自动填充默认值
        if (entity.getCreateBy() == null) entity.setCreateBy(Long.valueOf(StpUtil.getLoginIdAsString()));
        if (entity.getCreateAt() == null) entity.setCreateAt(LocalDateTime.now());
        // ...updateBy/updateAt/isDeleted 同理
    } else {
        // 非超级管理员：严格禁止设置审计字段，系统强制覆盖
        entity.setCreateBy(Long.valueOf(StpUtil.getLoginIdAsString()));
        entity.setCreateAt(LocalDateTime.now());
        entity.setUpdateBy(Long.valueOf(StpUtil.getLoginIdAsString()));
        entity.setUpdateAt(LocalDateTime.now());
        entity.setIsDeleted("NOT_DELETED");
        entity.setDeletedAt(null);
    }

    // 8. 根据字段权限清除不可操作的字段值
    if (!visibleFields.contains("tenant_name")) entity.setTenantName(null);
    if (!visibleFields.contains("tenant_type")) entity.setTenantType(null);
    // ...其他字段同理

    // 9. 保存租户
    this.save(entity);

    // 10. 更新父租户的 hasChildren 标记
    if (parentTenant != null && !Boolean.TRUE.equals(parentTenant.getHasChildren())) {
        this.update(new LambdaUpdateWrapper<SysTenant>()
                .eq(SysTenant::getId, parentTenant.getId())
                .set(SysTenant::getHasChildren, true));
    }
    return 1;
}
```

```java
public Integer updateTenantStatus(String id, String status) {
    // 1. 字段权限校验
    List<String> visibleFields = getTableFieldPermission("update");
    if (visibleFields == null || !visibleFields.contains("status")) {
        throw new BusinessException("无权修改租户状态字段");
    }

    // 2. 校验状态值合法性
    if (!GlobalEnum.TenantStatus.isValidCode(status)) {
        throw new BusinessException("无效的租户状态");
    }

    // 3. 查询待更新的租户
    SysTenant tenant = this.getOne(...);
    if (tenant == null) throw new BusinessException("租户不存在");

    // 4. 校验状态是否已处于目标状态
    if (status.equals(tenant.getStatus())) {
        throw new BusinessException("租户已处于该状态，无需重复操作");
    }

    // 5. 校验状态转换是否合法（状态机）
    if (!GlobalEnum.TenantStatus.isValidTransition(tenant.getStatus(), status)) {
        throw new BusinessException("不允许从" + ... + "状态转换为" + ... + "状态");
    }

    // 6. 启用租户时校验父租户状态
    if ("ENABLED".equals(status) && tenant.getParentId() != null && !Long.valueOf(0L).equals(tenant.getParentId())) {
        SysTenant parentTenant = this.getOne(...);
        if (parentTenant != null && "DISABLED".equals(parentTenant.getStatus())) {
            throw new BusinessException("父租户已停用，无法启用子租户");
        }
    }

    // 7. 更新当前租户状态
    LambdaUpdateWrapper<SysTenant> updateWrapper = new LambdaUpdateWrapper<SysTenant>()
            .eq(SysTenant::getId, id)
            .eq(SysTenant::getIsDeleted, "NOT_DELETED")
            .set(SysTenant::getStatus, status)
            .set(SysTenant::getUpdateBy, StpUtil.getLoginIdAsString())
            .set(SysTenant::getUpdateAt, LocalDateTime.now());

    if ("DISABLED".equals(status)) {
        updateWrapper.set(SysTenant::getDisableReason, "ADMIN_DISABLE");
    } else if ("ENABLED".equals(status)) {
        updateWrapper.set(SysTenant::getDisableReason, null);
    }
    this.update(updateWrapper);

    int updatedCount = 1;

    // 8. 如果是停用操作，利用 path 前缀匹配级联停用所有子租户
    if ("DISABLED".equals(status) && tenant.getPath() != null) {
        LambdaUpdateWrapper<SysTenant> childUpdateWrapper = new LambdaUpdateWrapper<SysTenant>()
                .likeRight(SysTenant::getPath, normalizePathPrefix(tenant.getPath()) + "/")
                .eq(SysTenant::getIsDeleted, "NOT_DELETED")
                .ne(SysTenant::getStatus, "DISABLED")  // 跳过已停用的子租户
                .set(SysTenant::getStatus, status)
                .set(SysTenant::getDisableReason, "PARENT_CASCADE:" + id)  // 标记级联停用
                .set(SysTenant::getUpdateBy, StpUtil.getLoginIdAsString())
                .set(SysTenant::getUpdateAt, LocalDateTime.now());
        updatedCount += this.update(childUpdateWrapper) ? 1 : 0;
    }
    return updatedCount;
}
```

```java
    if (path != null && path.endsWith("/")) {
```

### 5.4 分配父租户与环状结构检测

**位置**：`SysTenantServiceImpl.assignParentTenant`

```java
@Transactional(rollbackFor = Exception.class)
public Integer assignParentTenant(SysTenantAssignRTO assignParam) {
    // 1. 字段权限校验
    List<String> visibleFields = getTableFieldPermission("update");
    if (visibleFields == null || !visibleFields.contains("parent_id") || !visibleFields.contains("path")) {
        throw new BusinessException("无权修改租户层级关系字段");
    }

    // 2. 查询新父租户
    SysTenant newParent = this.getOne(...);
    if (newParent == null) throw new BusinessException("新父租户不存在");

    // 3. 校验新父租户状态
    if ("DISABLED".equals(newParent.getStatus())) throw new BusinessException("新父租户已停用");
    if ("EXPIRED".equals(newParent.getStatus())) throw new BusinessException("新父租户已过期");

    int updatedCount = 0;

    for (String subTenantCode : assignParam.getSubCode()) {
        // 4. 自身分配检查
        if (newParent.getTenantCode().equals(subTenantCode)) {
            throw new BusinessException("不能将租户移动到自身节点下");
        }

        // 5. 查询待移动的子租户
        SysTenant subTenant = this.getOne(...);
        if (subTenant == null) throw new BusinessException("子租户不存在: " + subTenantCode);

        // 6. 环状结构检测（核心）
        // 新父租户的 path 包含当前租户的 tenantCode 则说明新父租户是当前租户的后代
        // 使用精确匹配避免短编码误匹配（如编码"A"匹配到"GRP_A"的路径）
        if (newParent.getPath() != null && subTenant.getTenantCode() != null
                && (newParent.getPath().contains("/" + subTenant.getTenantCode() + "/")
                || newParent.getPath().endsWith("/" + subTenant.getTenantCode()))) {
            throw new BusinessException("不能将租户移动到自身子节点下，会形成环状结构");
        }

        // 7. 保存旧路径前缀，用于批量更新子孙节点
        String oldPathPrefix = subTenant.getPath();
        String newPath = newParent.getPath() + "/" + subTenant.getTenantCode();

        // 8. 更新当前子租户的父租户信息和路径
        this.update(new LambdaUpdateWrapper<SysTenant>()
                .eq(SysTenant::getId, subTenant.getId())
                .set(SysTenant::getParentId, newParent.getId())
                .set(SysTenant::getParentName, newParent.getTenantName())
                .set(SysTenant::getPath, newPath)
                .set(SysTenant::getUpdateBy, StpUtil.getLoginIdAsString())
                .set(SysTenant::getUpdateAt, LocalDateTime.now()));
        updatedCount++;

        // 9. 利用 path 前缀匹配更新所有子孙节点的路径
        if (oldPathPrefix != null) {
            List<SysTenant> descendants = this.list(new LambdaQueryWrapper<SysTenant>()
                    .likeRight(SysTenant::getPath, normalizePathPrefix(oldPathPrefix) + "/")
                    .eq(SysTenant::getIsDeleted, "NOT_DELETED"));
            for (SysTenant descendant : descendants) {
                // 替换旧路径前缀为新路径前缀
                String newDescendantPath = newPath + descendant.getPath().substring(oldPathPrefix.length());
                this.update(new LambdaUpdateWrapper<SysTenant>()
                        .eq(SysTenant::getId, descendant.getId())
                        .set(SysTenant::getPath, newDescendantPath)
                        .set(SysTenant::getUpdateBy, StpUtil.getLoginIdAsString())
                        .set(SysTenant::getUpdateAt, LocalDateTime.now()));
            }
        }

        // 10. 更新旧父租户的 hasChildren 标记
        if (subTenant.getParentId() != null && !"0".equals(subTenant.getParentId())) {
            long oldSiblingCount = this.count(new LambdaQueryWrapper<SysTenant>()
                    .eq(SysTenant::getParentId, subTenant.getParentId())
                    .eq(SysTenant::getIsDeleted, "NOT_DELETED"));
            if (oldSiblingCount == 0) {
                this.update(new LambdaUpdateWrapper<SysTenant>()
                        .eq(SysTenant::getId, subTenant.getParentId())
                        .set(SysTenant::getHasChildren, false));
            }
        }
    }

    // 11. 更新新父租户的 hasChildren 标记
    if (!Boolean.TRUE.equals(newParent.getHasChildren())) {
        this.update(new LambdaUpdateWrapper<SysTenant>()
                .eq(SysTenant::getId, newParent.getId())
                .set(SysTenant::getHasChildren, true));
    }
    return updatedCount;
}
```

```java
public SysTenantCommonVO switchTenant(SysTenantSwitchRTO switchParam) {

    if (targetTenantItem == null) {
        if (userContext.getTenantInfo().getInvalid() != null) {

                if (switchParam.getTargetTenantCode().equals(item.getTenantCode())) {

                    if ("DISABLED".equals(status)) throw new BusinessException("目标租户已停用，无法切换");

                    throw new BusinessException("目标租户状态异常，无法切换");
                }
            }
        }
        throw new BusinessException("当前用户不属于目标租户，无法切换");
    }

    // 4. 更新 Session 中的当前租户信息
    List<UserContextDTO.TenantItem> currentTenantList = new ArrayList<>();
    UserContextDTO.TenantItem currentTenantItem = new UserContextDTO.TenantItem();

    currentTenantItem.setIsPrimary(targetTenantItem.getIsPrimary());

    StpUtil.getSession().set(GlobalConstant.Session.USER_CONTEXT, userContext);

    // 6. 查询目标租户完整信息用于返回
    SysTenant targetTenant = this.getOne(...);
```

```java
private List<String> getQueryOperableFields() {
    UserContextDTO userContext = UserContext.getUserContext();

    UserContextDTO.FieldPermission fieldPerm = UserContext.getCurrentTenantFieldPermission();

// 获取指定操作类型的字段权限
private List<String> getTableFieldPermission(String operationType) {
    UserContextDTO userContext = UserContext.getUserContext();
    if (userContext == null) throw new BusinessException("无法获取用户上下文");

    UserContextDTO.FieldPermission fieldPerm = UserContext.getCurrentTenantFieldPermission();
    if (fieldPerm == null) return null;

    UserContextDTO.TableFieldPermission tableFieldPerm = null;
    if ("query".equalsIgnoreCase(operationType)) {
        if (fieldPerm.getQuery() != null) {
            tableFieldPerm = fieldPerm.getQuery().get(GlobalConstant.Table.TENANT);
        }
    } else if ("create".equalsIgnoreCase(operationType)) {
        if (fieldPerm.getCreate() != null) {
            tableFieldPerm = fieldPerm.getCreate().get(GlobalConstant.Table.TENANT);
        }
    } else if ("update".equalsIgnoreCase(operationType)) {
        if (fieldPerm.getUpdate() != null) {
            tableFieldPerm = fieldPerm.getUpdate().get(GlobalConstant.Table.TENANT);
        }
    } else {
        throw new BusinessException("不支持的操作类型: " + operationType);
    }

    if (tableFieldPerm == null || tableFieldPerm.getOperable() == null) return null;
    return tableFieldPerm.getOperable();
}
```

### 5.8 租户策略关联查询 SQL

**文件**：`nexusix-tenant/src/main/resources/mapper/SysTenantPolicyMapper.xml`

```sql
<!-- 查询租户策略列表，关联查询源实体和目标租户的详细信息 -->
<select id="queryPolicyListWithDetails" resultMap="CommonVOResultMap">
    SELECT
        tp.policy_code, tp.policy_name, tp.source_type,
        CASE
            WHEN tp.source_type = 'DEPT' THEN sd.dept_code
            WHEN tp.source_type = 'ROLE' THEN sr.role_code
            ELSE NULL
        END AS source_code,
        CASE
            WHEN tp.source_type = 'DEPT' THEN sd.dept_name
            WHEN tp.source_type = 'ROLE' THEN sr.role_name
            ELSE NULL
        END AS source_name,
        st.tenant_code, st.tenant_name,
        tp.bind_time, tp.status, tp.disable_reason,
        cu.user_name AS create_by_name, tp.create_at,
        uu.user_name AS update_by_name, tp.update_at,
        tp.is_deleted, tp.deleted_at
    FROM sys_tenant_policy tp
    LEFT JOIN sys_tenant st ON tp.tenant_id = st.id AND st.is_deleted = 'NOT_DELETED'
    LEFT JOIN sys_dept sd ON tp.source_type = 'DEPT' AND tp.source_id = sd.id AND sd.is_deleted = 'NOT_DELETED'
    LEFT JOIN sys_role sr ON tp.source_type = 'ROLE' AND tp.source_id = sr.id AND sr.is_deleted = 'NOT_DELETED'
    LEFT JOIN sys_user cu ON tp.create_by = cu.id AND cu.is_deleted = 'NOT_DELETED'
    LEFT JOIN sys_user uu ON tp.update_by = uu.id AND uu.is_deleted = 'NOT_DELETED'
    WHERE tp.is_deleted = 'NOT_DELETED'
    <if test="sourceType != null and sourceType != ''">
        AND tp.source_type = #{sourceType}
    </if>
    <if test="sourceId != null">
        AND tp.source_id = #{sourceId}
    </if>
    <if test="tenantId != null">
        AND tp.tenant_id = #{tenantId}
    </if>
    <if test="status != null and status != ''">
        AND tp.status = #{status}
    </if>
    ORDER BY tp.create_at DESC
</select>
```

> **关键设计**：通过 `CASE WHEN` 根据 `source_type` 动态关联 `sys_dept` 或 `sys_role` 表，避免多次查询。

### 6.3 级联停用数据流转

```

   │

updateTenantStatus("101", "DISABLED")
   │

   │      UPDATE sys_tenant SET status='DISABLED',
   │             disable_reason='ADMIN_DISABLE',

                 disable_reason='PARENT_CASCADE:101',

            AND status != 'DISABLED'  -- 跳过已停用的子租户

   ├── TEN00000001（id=101, path=TEN00000001）

   │
   └── TEN00000003（id=121, path=TEN00000001/TEN00000002/TEN00000003）
```

## 8. 未实现功能点清单

### 8.1 租户管理（SysTenantServiceImpl）

- [ ] **依赖 `UserContext.getUserContext()` 未实现**：由于公共模块的 `UserContext.getUserContext()` 方法体为空，所有字段权限相关功能实际无法正常工作（返回 null）。
  - **影响**：`getQueryOperableFields()` 和 `getTableFieldPermission()` 返回 null，查询接口将不限制字段（查询全部列），新增/修改接口将抛出 "无权新增/修改租户"（因为 visibleFields 为 null 时直接抛异常）。
  - **依赖**：需要先实现公共模块的 `UserContext.getUserContext()`。

- [ ] **`switchTenant` 依赖 `UserContext.getUserContext()`**：切换租户功能依赖从 Session 读取 UserContextDTO，若 `getUserContext()` 未实现则抛出 "无法获取当前用户上下文"。

- [ ] **缺少租户过期自动检测**：当前未实现定时任务检测 `expire_time < now()` 的租户并自动更新为 EXPIRED 状态。需要新增 `@Scheduled` 定时任务。

- [ ] **缺少租户配额管理**：`maxUsers` 字段已定义但未在用户新增时校验是否超过配额。

- [ ] **缺少租户层级深度限制**：`level` 字段已定义但未在新增/分配时校验是否超过最大层级深度。

- [ ] **删除租户未级联清理关联数据**：删除租户时仅校验子租户存在性，未清理 `sys_user_policy`、`sys_tenant_policy`、`sys_perm_policy` 等关联表数据。

### 8.2 租户策略管理（SysTenantPolicyServiceImpl）

- [ ] **依赖 `UserContext.getUserContext()` 未实现**：与租户管理相同，字段权限相关功能实际无法正常工作。

- [ ] **`batchBindToTenant` 未校验 sourceId 有效性**：绑定时不校验 sourceId 是否真实存在于 sys_dept 或 sys_role 表，可能产生脏数据。

- [ ] **缺少解绑时的关联清理**：解绑租户策略时未清理 `sys_user_policy` 中引用该策略的记录（targetId 指向该策略 id），可能导致用户仍能看到已解绑的部门/角色。
