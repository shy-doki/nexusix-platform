## 1. 模块概述

### 1.1 模块定位

公共模块由 `nexusix-common`、`nexusix-core`、`nexusix-boot` 三个子模块组成，是 NexusIX-Platform 多租户 SaaS 平台的基础设施层，为业务模块（IAM、租户管理、组织架构等）提供统一的：

- **响应包装**：统一 `ApiResponse` 结构与全局异常处理
- **通用枚举**：4 级权限禁用体系、租户状态机、用户状态、删除标记等核心枚举
- **注解 + AOP**：操作日志、数据范围、限流、防重提交切面
- **基础设施配置**：MyBatis-Plus、Redis、Sa-Token JWT、RabbitMQ、CORS
- **常量定义**：会话 Key、表名、角色编码、字段权限必选字段
- **用户上下文**：基于 Sa-Token Session 的 `UserContextDTO` 读取入口
- **启动引导**：组件扫描、Mapper 扫描、配置加密

### 1.2 技术栈

| 类别 | 选型 |
|------|------|
| 基础框架 | Spring Boot 3.3.4 |
| ORM | MyBatis-Plus 3.5.12 |
| 鉴权 | Sa-Token 1.42（JWT Simple 模式） |
| 缓存 | Redis（db0 业务 + db1 Sa-Token 独立） |
| 消息队列 | RabbitMQ |
| 对象转换 | MapStruct |
| JSON | Fastjson2 |
| 配置加密 | Jasypt（`@EnableEncryptableProperties`） |

### 1.3 关键设计原则

1. **4 级权限禁用体系**：`SYSTEM > TENANT > DEPT > ROLE > USER`，下层权限生效必须上层链路全部启用，任一层级禁用则该权限整体禁用。
2. **字段级权限**：通过 JSONB 字段 `field_operation` 存储 `{"field_name": ["READ","CREATE","UPDATE"]}`，按操作类型分类到 `query/create/update` 的 `operable/inoperable` 列表。
3. **统一审计字段**：所有业务表均含 `create_tenant/create_dept/create_role/create_by/create_at/update_by/update_at/is_deleted/deleted_at`，超级管理员可填写，非超级管理员由系统强制覆盖。
4. **软删除**：使用字符串枚举 `NOT_DELETED/DELETED`，而非物理删除或布尔标记。

| 枚举值 | code | desc | 禁用层级 |
|--------|------|------|----------|

| 枚举值 | code | desc |

#### 3.2.2 TenantStatus（租户状态机）

| 枚举值 | code | desc |
|--------|------|------|
| `PENDING` | `PENDING` | 待审核 |
| `ENABLED` | `ENABLED` | 正常 |
| `DISABLED` | `DISABLED` | 冻结 |
| `EXPIRED` | `EXPIRED` | 已过期 |

**状态机校验方法** `isValidTransition(from, to)`：

```
PENDING  → ENABLED  ✅（审核通过）
PENDING  → DISABLED ✅（审核拒绝）
ENABLED  → DISABLED ✅（管理员冻结）
DISABLED → ENABLED  ✅（管理员解冻）
ENABLED  → EXPIRED  ✅（自动过期）
EXPIRED  → ENABLED  ✅（续费恢复）
其他转换              ❌
```

#### 3.2.3 其他枚举

- `SubscriptionStatus` / `SubscriptionType`：订阅状态与类型
- `DefaultTenant`：默认租户编码
- `UserStatus`：`ENABLED / DISABLED / LOCKED`
- `RoleStatus`：`ENABLED / DISABLED`

所有枚举均使用 `@EnumValue`（MyBatis-Plus 自动映射）+ `@JSONField`（Fastjson 序列化），并提供 `getByCode / getByDesc / getByName / parse / isValidCode` 静态方法。

### 5.2 操作日志切面（OperationLogAspect）

**文件**：`nexusix-common/src/main/java/com/shy/nexusix/common/aspect/OperationLogAspect.java`

**核心机制**：

1. **ThreadLocal 存储**：`startTime` 与 `logData` 跨方法传递，避免参数污染。
2. **敏感参数脱敏**：识别 `password / oldPassword / newPassword / confirmPassword / token` 字段，替换为 `***`。
3. **业务类型分类**：通过 `@OperationLog(businessType = BusinessType.INSERT)` 注解标记，支持 `OTHER/INSERT/UPDATE/DELETE/GRANT/EXPORT/IMPORT/FORCE/CLEAN/SEARCH` 10 种类型。

**伪代码**：

```java
@Around("@annotation(operationLog)")
public Object around(ProceedingJoinPoint joinPoint, OperationLog operationLog) {
    // 1. 记录开始时间到 ThreadLocal
    startTimeThreadLocal.set(System.currentTimeMillis());

    // 2. 提取方法参数，对敏感字段脱敏
    Object[] args = joinPoint.getArgs();
    String maskedArgs = maskSensitiveFields(args);

    // 3. 执行业务方法
    Object result = joinPoint.proceed();

    // 4. 计算耗时，组装日志实体
    long costTime = System.currentTimeMillis() - startTimeThreadLocal.get();
    logData.setCostTime(costTime);
    logData.setBusinessType(operationLog.businessType());
    logData.setRequestArgs(maskedArgs);
    logData.setResponseResult(result);

    // 5. 异步写入日志（TODO：当前仅打印，未落库）
    return result;
}
```

### 5.3 限流切面（RateLimitAspect）

**文件**：`nexusix-common/src/main/java/com/shy/nexusix/common/aspect/RateLimitAspect.java`

**算法**：滑动时间窗口

**核心数据结构**：

```java
private final Map<String, RateLimitInfo> rateLimitMap = new ConcurrentHashMap<>();

class RateLimitInfo {
    long windowStart;       // 窗口起始时间
    int requestCount;       // 当前窗口请求数
    LinkedList<Long> timestamps;  // 精确时间戳队列（用于滑动窗口）
}
```

**限流类型**（`LimitType`）：

| 类型 | Key 构造方式 |
|------|--------------|
| `IP` | `ip:192.168.1.1` |
| `USER` | `user:1001` |
| `GLOBAL` | `global:methodName` |
| `IP_AND_USER` | `ip_user:192.168.1.1_1001` |

**算法流程**：

```
1. 请求到达，构造 limitKey
2. 从 Map 中获取 RateLimitInfo（不存在则创建）
3. 清理窗口外的过期时间戳（timestamps 中 < now - windowSize 的元素）
4. 判断当前窗口内请求数是否超过 limit
   ├── 超过 → 抛出 BusinessException("请求过于频繁，请稍后再试")
   └── 未超过 → 将当前时间戳加入 timestamps，放行
```

### 5.4 防重提交切面（RepeatSubmitAspect）

**文件**：`nexusix-common/src/main/java/com/shy/nexusix/common/aspect/RepeatSubmitAspect.java`

**核心机制**：

- 内存 `ConcurrentHashMap<String, Long>` 存储请求指纹与时间戳
- **指纹构造**：`SubmitType.IP` → IP；`USER` → userId；`IP_AND_USER` → IP+userId；`PARAMS` → IP+userId+参数Hash
- **过期清理**：当 Map 大小超过 **1000** 条时，触发清理逻辑，移除所有过期记录
- **默认间隔**：5 秒内重复提交将被拒绝

### 5.5 数据范围切面（DataScopeAspect）

**文件**：`nexusix-common/src/main/java/com/shy/nexusix/common/aspect/DataScopeAspect.java`

**数据范围类型**（`DataScopeType`）：

| 类型 | 说明 | 生成的 SQL 片段 |
|------|------|-----------------|
| `AUTO` | 自动（根据角色判断） | 由角色 dataScope 决定 |
| `ALL` | 全部数据 | 无限制 |
| `DEPT_AND_CHILD` | 本部门及子部门 | `dept_id IN (SELECT id FROM sys_dept WHERE path LIKE CONCAT(#{deptPath}, '%'))` |
| `DEPT_ONLY` | 仅本部门 | `dept_id = #{deptId}` |
| `SELF_ONLY` | 仅本人 | `create_by = #{userId}` |
| `CUSTOM` | 自定义 | `dept_id IN (#{customDeptIds})` |

**实现**：将构建的 SQL 片段存入 `ThreadLocal<String>`，供 MyBatis 拦截器在 SQL 拼接时读取注入。

### 5.7 Sa-Token JWT 配置

**文件**：`nexusix-common/src/main/java/com/shy/nexusix/common/config/SaTokenConfig.java`

```java
@Bean
public StpLogic stpLogicJwtForSimple() {
    return new StpLogicJwtForSimple();
}
```

- **模式**：JWT Simple（Stateless + Session 混合，Token 携带基础信息，详细权限存 Redis）

## 8. 未实现功能点清单

### 8.1 nexusix-core

- [ ] **`UserContext.getUserContext()` 方法体为空**：当前只有方法签名，无实现逻辑。注释中标注待实现"获取当前权限信息/租户信息/部门信息/角色信息/用户信息"。
  - **影响**：业务模块中调用 `UserContext.getUserContext()` 将返回 `null`，字段权限、租户切换等功能无法正常工作。
  - **建议实现**：
    ```java
    public static UserContextDTO getUserContext() {
        if (!StpUtil.isLogin()) {
            return null;
        }
        return (UserContextDTO) StpUtil.getSession().get(GlobalConstant.Session.USER_CONTEXT);
    }
    ```

### 8.2 nexusix-common

- [ ] **多租户插件 `TenantLineInnerInterceptor` 已注释**：当前未启用 MyBatis-Plus 的多租户自动过滤，改为在各 Service 中通过字段权限和 `LambdaQueryWrapper` 手动控制。后续若需统一处理可启用。
- [ ] **Sa-Token 全局过滤器已注释**：当前不拦截任何路径，由各 Controller 注解鉴权。若需统一登录校验可启用 `SaServletFilter`。
- [ ] **`OperationLogAspect` 日志未落库**：当前仅打印日志，未实现异步写入数据库表。需要新增 `sys_operation_log` 表与对应 Mapper。
- [ ] **`DataScopeAspect` 与 MyBatis 拦截器集成**：当前切面构建了 SQL 片段并存入 ThreadLocal，但缺少对应的 MyBatis 拦截器读取并注入到 SQL 中。需要实现 `Interceptor` 接口。
- [ ] **限流与防重提交基于内存**：`RateLimitAspect` 与 `RepeatSubmitAspect` 使用 `ConcurrentHashMap` 存储，单机有效。集群部署需切换为 Redis 实现。
- [ ] **CORS 仅允许 `localhost:8080`**：生产环境需要配置实际前端域名。

### 8.3 nexusix-boot

- [ ] **`application-dev.yml` 中 `jwt-secret-key` 为默认值**：生产环境必须更换为高强度随机密钥，并通过 Jasypt 加密。
- [ ] **缺少 `application-prod.yml`**：仅提供了开发环境配置，生产环境配置缺失。
